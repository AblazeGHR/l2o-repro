# LLM-Portfolio：LLM 自动算法选择实验

> Algorithm Portfolios 的核心思想：**没有万能算法**——不同实例结构适配不同算法，
> 组合 + 自动选择（Algorithm Selection）能系统性优于固定单算法。

## 实验设置

- 候选算法池（4 个，本地可移植实现，见 `portfolio/algorithms.py`，参考 ga-tsp-visualizer/tsp_ga.py）：
  1. `GA` —— 遗传算法（顺序交叉 OX + 交换变异，无局部搜索）
  2. `GA2opt` —— 遗传算法 + 2-opt 局部搜索
  3. `NN2opt` —— 最近邻 + 2-opt（多起点）
  4. `RI2opt` —— 随机插入 + 2-opt（多次重启）
- 每个算法每实例预算 **2.0s**（时间预算制，实测耗时见下）
- 实例集：**300** 个随机 TSP，n∈{15,20,25,30} 混合轮转，坐标为单位正方形 [0,1]²，全局 seed=42
- 特征（LLM 输入）：节点数 + 坐标均值/方差 + 包围盒 + 最近邻距离分布 + 聚类/均匀性指标 + 快速启发式回路长度
- LLM 选择器：`glm-4.5-air`（智谱，OpenAI 兼容，thinking disabled，max_tokens=512），
  输出 `{algorithm, confidence, reason}`（JSON）
- "事后最优" = 每个实例 4 个算法 2s 预算实测长度的最小值（组合内最优，非全局精确最优）

> 说明：由于实例规模小（n≤30）且各算法预算充足，实例内多算法并列最优很常见
> （并列率 100.0%）；LLM 选中任一并列最优算法即计为正确。

## 结论

1. **关于"没有万能算法"**：在当前实例集上存在"万能"算法：固定 **GA2opt+RI2opt** 在全部 300 个实例都达到组合最优（gap 0.000%，达到最优率 100%）。这并不否定 Algorithm Portfolios 的动机，而是说明：当实例规模小（n≤30）、几何结构单一（均匀分布）、时间预算充足时，各算法的解质量差距没有拉开，组合选择的优势无从体现。要验证组合价值，必须引入算法表现分歧更大的实例分布（更大 n、聚类/环形等结构化几何、更紧的时间预算）。
2. **LLM 选择器的行为**：LLM 选择器事实上收敛为固定策略：**NN2opt** 被选中 295/300 次（98.3%），从未（或几乎从未）逐实例切换算法。其平均 gap 为 0.2800%，优于随机选择（gap 0.2800% vs 5.4153%）；劣于最优单算法固定策略（GA2opt: 0.0000%）。也就是说，LLM 没有真正执行"逐实例算法选择"，而是退化为单一算法策略——且该算法（NN2opt）并非组合内最优单算法（NN2opt 达最优率仅 81.0%，低于 GA2opt/RI2opt 的 100%）。这暴露了静态单次 LLM 预测的局限：若没有实例间的对比/反馈信号，LLM 倾向于重复训练数据中占优的策略，而非做真正的 Portfolio 决策。
3. **改进方向**：为让 Algorithm Portfolio 的选择优势真正显现，需要算法表现分歧更大的实例分布——
   更大规模（n=50~200）、更丰富的几何结构（聚类/环形/网格/真实地理数据）、更紧的时间预算；
   同时 LLM 选择器应引入训练/反馈信号（用历史实例的真实最优做 few-shot 或微调，或做成在线
   warm-up 选择），避免退化为单一策略。
