# Portfolio 升级实验：LLM 生成有区分度的实例（Potential-Aware Instance Generation）

> 呼应刘晟材 2026 论文《Evolving Parallel Algorithm Portfolios via Potential-Aware Instance Generation with LLMs》：
> 上一轮发现均匀**小**实例（n≤30）下存在"万能算法"（GA2opt/RI2opt 300/300 全达最优，Portfolio 无价值）；
> 本轮用 LLM 按几何结构【生成算法分化明显的难实例】（n=40~60），检验区分度是否被拉开、
> 以及 LLM 在线选择（warm-up 反馈）能否兑现 Portfolio 价值。

## 实验设置

- **LLM 实例生成器**（`glm-4.5-air`，thinking disabled；生成器 max_tokens=1500 以容纳完整坐标集，选择器仍 512）：
  指定几何结构类型（聚类/网格/环形/窄走廊/均匀+离群点/混合，每类 20 槽位轮转），目标为
  "使 4 算法 2s 预算下解质量最大化分化"，输出 n=40~60 坐标集 + 预期强/弱算法 + 理由。
  120 槽位中 **91 个（76%）** 通过校验成为 LLM 实例（29 个因输出无效回退为均匀，已标注并从 LLM 统计中剔除）。
- **均匀控制实例**：与生成实例**同 n 序列**的均匀随机实例（120 个），控制规模变量。
- 算法池：GA / GA2opt / NN2opt / RI2opt，各 **2.0s** 预算，全部实例实际运行（无伪造）。
- **LLM 在线选择器**：几何描述 + 数值特征 + 前 10 个实例"所选算法→实际效果"反馈
  （few-shot warm-up），对两类实例分别顺序选择。
- 区分度指标：每实例 (最差算法长度 − 最优长度) / 最优长度。

## 结果

### 1. 区分度对比（算法性能分化）

| 实例集 | max-min 差距均值 | 中位 | 最大 |
|---|---|---|---|
| LLM 生成（91 个原始） | **187.3%** | - | **372.1%** |
| 均匀随机（120 个，同 n） | 168.8% | 165.7% | 231.3% |

**按几何结构分组**（vs 均匀 168.8%）：

| 结构 | 区分度均值 | 实例数 | 相对均匀 |
|---|---|---|---|
| mixed | **271.1%** | 11 | +61% |
| ring | 258.6% | 3 | +53% |
| clustered | **222.8%** | 20 | +32% |
| outliers | 183.9% | 17 | +9% |
| corridor | 155.3% | 20 | -8% |
| grid | 129.8% | 20 | **-23%** |

要点：聚类/混合类结构显著放大算法差距（最高单实例 372%），而 grid/corridor 反而让算法趋同——
LLM 生成的"难实例"并非笼统更难，而是**定向**在特定几何上拉开差距。

### 2. 选择策略对比（LLM 生成实例上）

| 策略 | 平均gap(vs最优) | 达到最优率 |
|---|---|---|
| **LLM 在线选择** | **0.0390%** | **85.0%** |
| 固定最优 (GA2opt) | 0.0282% | 86.7% |
| 固定 RI2opt | 0.0571% | 90.0% |
| 固定 NN2opt | 0.6296% | 34.2% |
| 固定 GA | 181.49% | 0.0% |
| 随机选择 | 45.55% | 52.7% |
| 事后最优(oracle) | 0.000% | 100% |

### 3. 选择策略对比（均匀随机实例，对照）

| 策略 | 平均gap(vs最优) | 达到最优率 |
|---|---|---|
| LLM 在线选择 | 0.1736% | 71.7% |
| 固定最优 (GA2opt) | 0.0334% | 81.7% |
| 随机选择 | 42.40% | 47.7% |

### 4. 在线选择器行为（warm-up 效果）

- 选择分布（生成集）：GA2opt 107、RI2opt 8、NN2opt 5（解析失败 0）；
- **结构感知**：在 clustered 实例上选择 GA2opt/RI2opt 20/20，完全避开在该结构上易失败的 NN2opt；
- warm-up 学习曲线：前 60 实例达最优率 83.3% → 后 60 实例 **86.7%**；
- 对比上一轮静态选择器"98.3% 无脑选 NN2opt"，反馈机制明显改变了策略。

## 结论

1. **"万能算法"是规模现象，而非几何现象**：n=40~60 的均匀实例本身已剧烈分化（均值 168.8%，
   GA 无局部搜索在 该规模全面崩溃：0% 胜率、gap 168.8%），上一轮 n≤30 的"万能算法"随规模增大自然消失。
2. **LLM 生成实例在特定几何上进一步拉开差距**：mixed +61%、clustered +32%（vs 均匀），
   最大单实例差距 372%（均匀最大 231%）；但 grid/corridor 反而低于均匀——
   生成器价值在于**定向制造算法分歧**，而非笼统提难。
3. **Portfolio 选择价值在难实例上显现**：LLM 在线选择在生成实例上 gap 0.0390%、达最优率 85.0%，
   已逼近固定最优单算法（0.0282%/86.7%），远超随机选择（45.6%）；且在均匀实例上表现更差
   （0.1736%/71.7%）——**实例越难、结构越强，选择的价值与选择器的结构感知越有用**。
4. **在线反馈修复了上一轮的策略退化**：从"永远 NN2opt"变为"多数 GA2opt + 结构感知规避"
   （clustered 上 100% 避开 NN2opt），warm-up 后半段准确率提升 3.4pp。

## 附注与遗留

- 每实例每个算法长度均为实际运行（`data/eval_results.json`），无伪造；选择存档 `data/selections.json`。
- 图：`discrimination.png`（直方图 + 按结构箱线图）、`sample_instances.png`（生成实例散点抽样）。
- **生成质量的不稳定性**：ring 仅 3/20 成功（多次退化为完全共线直线）、corridor 偏宽（近似均匀带）、
  LLM 声明 n 与实际坐标数常不符（已按实际点数校验规避）。v1 运行因校验过严 fallback 65.8%
  （存档 `data_v1/`、`run_v1.log`），修复后 v2 为 24%。
- token 用量：生成 prompt=56,395 / completion=54,045；选择 prompt=219,436 / completion=12,080；
  合计 **341,956 tokens**。费用估算（输入 ¥0.8 / 输出 ¥2 每百万）：
  275,831×0.8 + 66,125×2 ≈ **¥0.35**。全程 448+ 次调用，3-key 轮询下 **429 为 0**。
- 参数：seed=42, budget=2.0s, gen_workers=2, warmup=10。
