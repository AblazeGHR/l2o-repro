# qaoa-repro —— 理解文档

> 目的：讲清这个项目复现了什么、结果如何、与刘晟材老师工作的关系（诚实标注，可验证）。

## 1. 项目是什么

复现 **Neural QAOA²**（ICML 2026，刘晟材通讯作者，arXiv:2605.13072）：一个**端到端可微框架**，联合生成"图划分 + 参数初始化"，用于**量子组合优化**（QAOA 受限于量子比特数，需把大图划分子图）。

- 仓库：github.com/0SliverBullet/Neural-QAOA-Squared（官方，含预训练权重）
- 本机做法：复用 E 盘 torch 2.9 cu129（官方 cu121 与 RTX 5060 Blackwell 不兼容）+ 装 pennylane/torch-geometric；**下载官方预训练权重直接评估**（不训练，8GB 显存不适合训练）；两处最小兼容补丁。
- 评估：MaxCut 4 实例（bqp50-1/2, be100.1/2）× 13 配置 × 3 runs = 56/56 全部成功。

## 2. 结果（真实数字）

| 划分策略 | 4 实例平均近似比 |
|---|---|
| **boundary d=2** | **0.910**（本批最佳） |
| modularity d=2 | 0.905 |
| random / KL | 0.87–0.89 |
| **JointGen+Critic d=1** | **0.882** |

**关键结论（与论文一致）**：在小规模（50-100 节点）上，JointGen+Critic **并不明显优于**传统图划分（boundary/modularity）——论文 Figure 显示其优势在 **n≥200 才显现**。我们复现出的正是论文的结论，说明实验设置理解正确。

## 3. 与刘晟材老师工作的关系

- 🔴 **直接相关（他的最新顶会工作）**：刘晟材是这篇 ICML 2026 论文的**通讯作者**。复现它的 baseline = "我读懂并复现了您最新的工作"，是**展示价值最高**的一块。
- 属于他的研究主线 **AI for Quantum and Material**（学习优化方法用到量子计算）。
- 与 LMEA（LLM 优化器）呼应：都是"用学习替代/辅助手工设计"，量子版是"用可微网络学图划分+参数"。

## 4. 技术要点（遇到并解决的）

- **Blackwell 兼容**：官方环境是 cu121 老 torch，RTX 5060（sm_120）需要 cu128+ → 复用已有 torch 2.9 cu129；
- **Windows wheel 缺失**：pymetis 无 Windows 版 → import-only stub；torch_scatter 无 wheel → 换 torch_geometric scatter；
- **硬件边界**：8GB 显存不适合训练 critic/generator → 用官方权重直接评估（合理取舍，诚实标注）。

## 5. 遗留事项（诚实）

- JointGen+Critic 官方代码仅支持 depth=1（硬编码）；depth 2/3 会 AssertionError；
- 更大规模（bqp250/500）未跑——若想展示论文 Figure 的"大图优势"，可在服务器/更大显存机器上补；
- 训练流程未跑（8GB 限制）。

## 6. 学习要点（从代码学什么）

- QAOA 原理：量子近似优化算法（哈密顿量、泡利矩阵、circuit）；
- 图划分为什么能扩展 QAOA 到大规模（分治思想）；
- "可微量子评估器作为性能代理"——用学习替代精确模拟的 L2O 思想在量子域的体现。
