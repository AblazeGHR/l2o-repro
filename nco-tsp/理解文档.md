# nco-tsp —— 理解文档

> 目的：讲清这个项目做什么、结果如何、与刘晟材老师工作的关系（诚实标注，可验证）。

## 1. 项目是什么

复现 **Kool et al. (ICLR 2019)《Attention, Learn to Solve Routing Problems!》**（arXiv:1803.08475）：
用 **Transformer 编码器 + attention pointer 解码器** 做策略网络，用 **REINFORCE 策略梯度 + greedy rollout baseline** 训练，求解 **TSP20**（坐标单位正方形均匀分布）。

- 代码来源：官方仓库 `wouterkool/attention-learn-to-route`（commit c9abf41），仅做了两处 Python 3.12/torch 2.6 兼容补丁。
- 训练规模：80 epochs，约 **16M 训练实例**，RTX 5060 GPU。
- 训练命令、日志、脚本都在本目录（见 README.md）。

## 2. 结果

- **验证收敛**：val avg_cost **3.8518**（论文 Kool et al. 的 TSP20 约 3.83，差距 <0.02，收敛充分）✅
- 收敛曲线：`results/training_curves_progress.png`
- 对比表：`results/comparison_tsp20.csv`

| 方法 | 平均 tour length（TSP20） |
|---|---|
| Attention Model (greedy, ours) | **3.8601 ± 0.307** |
| Nearest Neighbour | 4.4680 ± 0.535 |
| 2-opt (NN init) | 3.9307 ± 0.350 |
| Random Insertion | 3.9984 ± 0.358 |
| OR-Tools (GLS) | 3.8302 ± 0.299 |
| Kool et al. 2019（论文） | ~3.83 |

✅ **评估已修复（2026-08-28）**：原对比表 7.23 的根因是 `eval_trained.py` 静默加载了未训练模型（当时目录里只有 epoch-0.pt）。已加 `--epoch` 显式指定 checkpoint 并打印加载文件，重跑后 AM = **3.8601**，与训练验证 3.85 一致、逼近论文 3.83。**神经方法 ≈ OR-Tools > 简单启发式**，符合 Kool 论文结论。

## 3. 与刘晟材老师工作的关系

- 🟡 **直接相关**：**神经组合优化（NCO）正是刘的研究方向**——他写过 NCO 领域的系统评估论文 *How Good Is Neural Combinatorial Optimization? A Systematic Evaluation on the TSP*（IEEE CIM 2023，arXiv:2209.10913）。本项目训练"神经求解器 + 与经典方法对比"的完整闭环，正是那篇论文评估框架的实操版；NCO 也是其 L2O（用学习替代手工算法）主线的一部分。
- 🟢 **领域基础**：Kool 方法是 NCO 的标准 baseline（非刘本人工作）——读懂它是进入这个领域的必经之路；REINFORCE 来自 Sutton & Barto（教材已下载，见 `教材/RLbook2020.pdf` 第 13 章）。

## 4. 学习要点

- 策略网络怎么把 TSP 建模为"自回归逐点选下一个城市"；
- REINFORCE 与 rollout baseline 为什么能降方差（对照 RL 教材第 13 章）；
- 看收敛曲线：val 从 ~4.1 降到 3.85 的平台过程；
- 对比表怎么读：经典启发式（NN/2-opt/RI）与神经方法的差距。

## 5. 升级方向

- 换 TSP50/100 看泛化（NCO 的已知弱点）；
- 画"不同 epoch 的 eval 曲线"（脚本已支持 `--epoch`，可循环复用）；
- 与 `ga-tsp-visualizer` 衔接：同一个实例上 GA vs 神经求解器 vs LLM 优化器三方对比——这就是刘老师论文里的"算法对比"视角。
